## Conventions

- Window 1280x800 unless a step row says otherwise. At zoom 1 that is a grid of 80 columns by 50 rows (cells 16 px). The fortress screen puts the map on rows 0-44, the log strip on rows 45-47 (three announcement lines) and the two status rows on rows 48-49. An open panel takes the right 36 columns.
- Every step has a screenshot (`.png`) and a cell-buffer dump (`.txt`). The dump header lists the exact keys and mouse actions of the step, the tick, whether the clock was paused (speed 0), the screen id, the open panel, the viewport and grid size, and console errors/warnings since the previous step. The grid follows as `NN|text` lines, then the log strip rows and the status rows. Cell colours are only in the screenshot.
- "Keys / clicks" are verbatim: `key X` is a real keyboard press through the browser; `left-click cell(col C, row R) px(X,Y)` is a real mouse click at the centre of that cell; `hook step(n)` / `hook step to tick n` is a call to the test hook's `step`, used only to advance the clock (the clock is otherwise paused, as the fortress opens paused); `hook submit` is a call to the hook's command call.
- `[KEY - reason]` after a key marks a point where a mouse-only run had to use the keyboard because no mouse way was found; the reason is what was tried.
- "What the game showed" is taken from the buffer: for the fortress screen the three log-strip lines, the two status rows and (with a panel open) the first lines of the panel; for other screens the first non-blank lines of the screen (for the world map, the right-hand panel).
- "screen unchanged from step N; no screenshot saved" means the cell buffer (glyphs and colours) was identical to the previous step. The dump file is still saved.
- Tick numbers after a `Space` resume advance with real time while the clock runs (a few ticks per second at 1x).
- Default random seeds are repeatable in this capture because `Math.random` is replaced by a fixed generator before the page loads (the game builds its default seed `deep-<n>-<k>` from `Math.random`). This changes nothing else in the game.
- Console: warnings and errors (`console.error`, `console.warn`), uncaught exceptions (`pageerror`) and failed requests were collected for every step.

## Flow 2: New player, keyboard only, from the main menu

Method: Playwright keyboard events only (the mouse was never moved or clicked), from the main menu, same default seed (`deep-3588-1`), same region as flow 1 (region id 2339, "Bitterbrae"), default party and supplies. The `Enter` placements aim by panning the camera until the tile wanted is the map-centre tile (a keyboard user has no other way to aim, see below); the number of key presses used to aim is in each step's text. Free 3x3 patches near the wagon were found with the hook's readers (setup only). The only non-key action besides the hook's `step` is none.

Keyboard could do (observed): the whole menu, world generation, walking the world-map cursor to a region (7 key presses: `Shift+ArrowLeft`/`ArrowLeft x6`/`ArrowUp x4` in the dump), embark (`Enter` on the embark screen embarked at once), every panel by letter, designations, stockpile, farm plot, meeting area, bedroom, workshop, door tool, an order by typing a filter, the stockpile preset dropdown, game menu, rename.

Keyboard could not do (observed, each tried):
- Choose a crop for a farm plot. In the farm plot editor these keys were tried and the four season dropdowns stayed "none": `ArrowDown` (pans the map), `Enter`, `ArrowDown`, `Enter`, `1`, `ArrowRight`, `Space` (resumes the clock), `Space` (pauses it again).
- Open the Calendar panel: `Tab` (toggles the sidebar), `Tab`, `F2`, `F3` were tried; it opens by clicking the date.
- Aim at a tile other than the map-centre tile (or a look cursor set by `k`): `Enter` with a tool uses the look cursor if one is set, else the map centre. With the sidebar open the camera cannot go past x = 0, so the left-most tile that can be the map centre is x = 22 (probe step `probe-left-edge`: after `Shift+ArrowLeft x5` the centre was x=22, camera x=0); the wagon is at x=1, y=47. Tiles with x < 22 (with a panel open) were not reachable by `Enter`.
- Hover for the tile summary or tooltips, double-click to centre on a unit, drag-select a rectangle for item commands: no key was found for these in this run (not individually tried).
Quirk observed: pressing `k` twice closes the Look panel but leaves the look cursor set (dump header `look-cursor`); later `Enter` presses with a tool then acted at the cursor tile, not at the map centre. `Escape` with a panel open clears it. This was found in an earlier run of this script; the final run clears the cursor with `k`, `Escape` before the designations.
