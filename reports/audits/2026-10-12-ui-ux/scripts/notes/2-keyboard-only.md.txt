Method: Playwright keyboard events only (the mouse was never moved or clicked), from the main menu, same default seed (`deep-3588-1`), same region as flow 1 (region id 2339, "Bitterbrae"), default party and supplies. The `Enter` placements aim by panning the camera until the tile wanted is the map-centre tile (a keyboard user has no other way to aim, see below); the number of key presses used to aim is in each step's text. Free 3x3 patches near the wagon were found with the hook's readers (setup only). The hook's `step` was used only to advance the clock.

Keyboard could do (observed): the whole menu, world generation, walking the world-map cursor to a region (7 key presses: `Shift+ArrowLeft`/`ArrowLeft x6`/`ArrowUp x4` in the dump), embark (`Enter` on the embark screen embarked at once), every panel by letter, designations, stockpile, farm plot, meeting area, bedroom, workshop, door tool, an order by typing a filter, the stockpile preset dropdown, game menu, rename.

Keyboard could not do (observed, each tried):
- Choose a crop for a farm plot. In the farm plot editor these keys were tried and the four season dropdowns stayed "none": `ArrowDown` (pans the map), `Enter`, `ArrowDown`, `Enter`, `1`, `ArrowRight`, `Space` (resumes the clock), `Space` (pauses it again).
- Open the Calendar panel: `Tab` (toggles the sidebar), `Tab`, `F2`, `F3` were tried; it opens by clicking the date.
- Aim at a tile other than the map-centre tile (or a look cursor set by `k`): `Enter` with a tool uses the look cursor if one is set, else the map centre. With the sidebar open the camera cannot go past x = 0, so the left-most tile that can be the map centre is x = 22 (probe step `probe-left-edge`: after `Shift+ArrowLeft x5` the centre was x=22, camera x=0); the wagon is at x=1, y=47. Tiles with x < 22 (with a panel open) were not reachable by `Enter`.
- Hover for the tile summary or tooltips, double-click to centre on a unit, drag-select a rectangle for item commands: no key was found for these in this run (not individually tried).
Quirk observed: pressing `k` twice closes the Look panel but leaves the look cursor set (dump header `look-cursor`, steps `look-at-wagon-centre` and `look-enter`); in a trial run of this script, later `Enter` presses with a tool then acted at the cursor tile, not at the map centre. `Escape` with a panel open clears the cursor (step `look-escape`); the recorded run does that with `k`, `Escape` before the designations.
