Setup: session 1 starts at the main menu with defaults, toggles the colorblind palette in Settings (steps `A-*`), embarks at region 2339 of seed `deep-3588-1` with the colorblind palette on, makes a stockpile, a farm plot, a bedroom and a chop designation so that zone and designation tints are on screen (`B-*`), toggles the palette back (`C-*`, same site), then window sizes (`E-*`), long names (`F-*`), Help pages (`G-*`) and the Zoom setting (`D-*`, last, because it changes the grid for the rest of the session). Session 2 is the 80-dwarf reference fortress stepped 7,200 ticks, to have many log lines (`H-*`). Session 3 retires a fortress to reach the legend screen (`I-*`). Window sizes tried, with the grid each gave (see the dump headers): 1280x800 -> 80x50, 1920x1080 -> 120x67, 2560x1440 -> 160x90, 3840x2160 -> 240x135, 960x540 -> 80x45, 640x360 -> 80x45 (below 960x540 the 80x45 grid is kept and the canvas is scaled). The smallest size at which the minimum grid fits without scaling (960x540) is the smallest used in flow 4. Observed in flow 4 (step `B-back-1280` onward) and again at the end of this flow (`E-back-1280x800-fortress`): after the window is made smaller than the zoom allows and then returned to 1280x800, the grid stays at the smaller cell size (106x66 cells instead of 80x50).

Long names: the dwarf rename input (units panel, `Shift+N`) was given 30 characters, then 26 (the spec limit is 24); the fortress rename was given 39 characters (the limit is 32); steps `F-*` show what each panel then displayed. The Help panel was paged with `PageDown` (steps `G-help-1` .. `G-help-8`). The Log panel was paged in the reference fortress (steps `H-log-*`); its filter keys are in steps `H-log-tab` and `H-log-slash`. The colour palettes are only visible in the screenshots (the dumps hold glyphs, not colours).
