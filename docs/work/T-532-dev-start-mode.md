# T-532 — A testing start mode with an unlimited loadout

**Source:** the owner, 2026-11-08 · **Size:** M · **Needs:** — · **Status:** open

## Why

The owner: "have a dev/testing starting mode where starting loadout is unlimited - one can have many starting dwarves, with high arbitrary skills, and many items. Have a preset for that mode. Idea is to start a fortress to test out some of the features/skills without getting to them normally."

## What to do

- A clearly labelled testing mode on the embark screens (not the default; say so in the UI): no point budget; any number of starting dwarves; any skill at any level, set per dwarf or for all at once; any item in any quantity and material, including late items (cut gems, bars, staffs and wands with stones, vials, enchanted gear).
- A preset for it that gives a broad test fortress at once: for example a dozen dwarves covering every labour at a high level including runecraft, plenty of food, drink, logs, stone, bars, gems and vials, a squad's kit, and glowstone and glowcap seed, so a player can try runecraft, smithing, farming and combat straight away.
- Fortresses started in this mode are marked as such (save header, legend), so they are not mistaken for normal play, and achievements or milestones that would be cheapened say so or are skipped.
- Works with T-531: a testing loadout can be saved and loaded.
- Spec: 02 and the screens doc. e2e: start in testing mode with the preset and play a few days.
