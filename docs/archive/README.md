# Archive

Closed work, kept for its history. Nothing here is current, and nothing here is a rule: the rules are in the specification (`docs/00-` … `docs/04-`). The specification never links into this folder. A file here is not edited after it arrives, except to keep its links working when another file moves.

| Folder | Contents |
|---|---|
| [`build-plan/`](build-plan/README.md) | The plan that built v1.0.0: the plan's index, the milestone task files `M0-skeleton.md` … `M8-polish.md`, the task checklist [`PROGRESS.md`](build-plan/PROGRESS.md), and [`roadmap.md`](build-plan/roadmap.md) (the four waves in which the specification was written) |
| [`fixes/`](fixes/README.md) | The audit fixes F-01 … F-16, each with its decisions and the spec amendments it made. F-17 closed on 2026-10-07 and is in [`tasks/`](tasks/F-17-balance-followups.md) |
| [`ui-fixes/`](ui-fixes/README.md) | The UI fixes from the v1.0.0 UI audit: decisions D-U1 … D-U10 and the task table at archiving. All eight U tasks are closed; U-02 and U-07's briefs are in `tasks/` |
| `tasks/` | Closed task files and the completed documentation migration plan, moved here from `docs/work/` when the task closes |
| [`decisions-archive.md`](decisions-archive.md) | Rows taken out of the decision log because they are superseded or purely historical, each kept whole; the resolved contradictions C-001 … C-008 among them |

How a task file gets here is in [`../process/agent-workflow.md`](../process/agent-workflow.md) § Closing a task. The gate reports and audits these documents cite are under [`../../reports/`](../../reports/).
